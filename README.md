Gobble Dash is a complete original turkey escape game: a turkey flees the farm on Thanksgiving, outrunning the farmer, hopping fences and ovens, dodging falling carving knives and gobbling corn on the 600-metre run to the safety of the forest.

## Run it

```sh
# Play in a desktop browser (no build step, no network):
open game/index.html
# or serve the folder with any static server, then open it.

# Build the submission output (game/ + screenshots/ + dossier.json):
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Move with ← → or A / D, hop with Space or ↑, pause with P, mute with M. Click also hops. Reach the forest to escape — if the farmer catches you, or you run out of lives, it's Thanksgiving dinner.
